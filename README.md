# 💻 Juego del Ahorcado en consola

## 📌 Descripción

Este proyecto consiste en el desarrollo del juego **Ahorcadito** en **Java**, donde el usuario debe adivinar palabras ocultas letra por letra.  

Las palabras están organizadas en **categorías** y se cargan desde un archivo **CSV**, permitiendo trabajar con **cadenas de texto (String)** y el uso de **métodos (funciones)**.  

El objetivo es aplicar conceptos fundamentales como manipulación de texto, lógica de programación y estructuras básicas en Java.

---

## 🎯 Objetivos del proyecto

* Implementar el juego del **ahorcado en consola**.
* Utilizar **archivos CSV** para cargar datos dinámicamente.
* Aplicar métodos de **String** como `split()`, `charAt()`, `length()` y `toLowerCase()`.
* Usar **funciones (métodos)** para organizar el código.
* Generar palabras aleatorias usando `Math.random()`.
* Fortalecer la lógica de programación.

## 📋 Funcionalidades del proyecto

El proyecto incluye las siguientes características:

1. **Lectura de palabras desde archivo CSV**  
2. **Selección aleatoria de palabras**  
3. **Sistema de intentos del jugador**  
4. **Validación de letras ingresadas**  
5. **Visualización del progreso de la palabra**  
6. **Uso de categorías**  
7. **Interacción por consola**  

---

## ⚠️ Consideraciones

* El archivo **CSV** debe estar bien estructurado (categoría, palabra).  
* Se deben validar las entradas del usuario para evitar errores.  
* El uso de `Math.random()` permite variar las palabras en cada partida.  
* Es importante manejar correctamente los **intentos del jugador**.  
* El programa funciona completamente en consola.
